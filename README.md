### 🛡️ [PhishGuard-AI](https://github.com/orkun022/PhishGuard-AI)
**Intelligent Phishing URL Detection System**

AI-powered web app that detects phishing URLs using ML. Extracts **16 URL features** and analyzes through Random Forest, SVM & XGBoost. Features a **self-learning pipeline** — the model retrains itself after 50 verified scans.

🔗 **[Live Demo →](https://phishguard-ai.streamlit.app)**

`Python` `Scikit-learn` `XGBoost` `Streamlit`

### 🌐 [NetShield-AI](https://github.com/orkun022/NetShield-AI)
**Network Intrusion Detection System (IDS)**

AI-based IDS that classifies network traffic into **4 attack types**: DoS, Probe, R2L, U2R. Uses behavior-based analysis instead of signatures, enabling **zero-day attack detection**. Compares supervised (Random Forest) vs unsupervised (Isolation Forest) approaches.

`Python` `Random Forest` `Isolation Forest` `Streamlit`
